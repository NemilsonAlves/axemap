# 03 — Benchmark Nacional

## Concorrentes Diretos Brasileiros

### 1. AxéCloud
| Item | Detalhe |
|------|---------|
| **URL** | axecloud.com.br |
| **Tipo** | SaaS de gestão para terreiros |
| **Módulos** | Painel do zelador, cadastro de filhos de santo, calendário de giras, financeiro com Pix, mural de avisos, galeria, biblioteca, loja do axé, almoxarifado, WhatsApp API, portal público |
| **Pontos Fortes** | Mais completo SaaS do segmento (~15 módulos). Terminologia litúrgica real. 30 dias grátis. |
| **Pontos Fracos** | Apenas PWA (sem app nativo). Preço não público. Sem diretório público consolidado. Sem marketplace externo. |
| **Monetização** | Assinatura mensal (plano único, valor sob consulta) |
| **Lições** | Referência de profundidade no SaaS. Precisamos ser tão ou mais completos. |

### 2. Terreiros do Brasil
| Item | Detalhe |
|------|---------|
| **URL** | terreirosdobrasil.com.br |
| **Tipo** | Diretório + classificados + app mobile |
| **Métricas** | ~5.000 anúncios, ~3.265 usuários, ~1.857 terreiros verificados |
| **Diferenciais** | App mobile, categorização por nação, classificados, blog, parceria c/ Ministério da Cultura |
| **Pontos Fracos** | Design confuso, performance baixa, monetização incipiente, navegação poluída |
| **Monetização** | Cadastro gratuito, classificados pagos |
| **Lições** | Maior base atual — precisamos superar em UX e performance. Eles têm ~5 anos de vantagem. |

### 3. Criado na Pemba
| Item | Detalhe |
|------|---------|
| **URL** | criadonapemba.com.br |
| **Tipo** | Rede social + comunidade + cursos + certificação |
| **Diferenciais** | Única rede social do segmento. Certificação oficial de casas. Cursos EAD. Apoio jurídico. |
| **Pontos Fracos** | Navegação confusa, design amador, performance lenta, baixa adoção (~40 membros online) |
| **Monetização** | Assinatura anual, venda de cursos, certificação, loja |
| **Lições** | Rede social é desejada mas exige execução impecável. Eles tentaram fazer tudo e fizeram tudo mediano. |

### 4. Guia de Terreiros
| Item | Detalhe |
|------|---------|
| **URL** | guiadeterreiros.com.br |
| **Tipo** | Diretório básico com mapa |
| **Diferenciais** | Mapa interativo, foco exclusivo em conectar pessoas a terreiros |
| **Pontos Fracos** | Site básico, sem filtros avançados, sem app, sem eventos, sem monetização |
| **Monetização** | Nenhuma aparente |
| **Lições** | Prova que existe demanda por busca geográfica de terreiros |

### 5. 1banda
| Item | Detalhe |
|------|---------|
| **URL** | 1banda.com |
| **Tipo** | Portal de conteúdo + mapa Google Maps |
| **Diferenciais** | Conteúdo rico, calendário espiritual, múltiplos canais (Instagram, TikTok, YouTube) |

## Posicionamento Recomendado

Nenhum concorrente oferece **tudo** em uma plataforma. O AxéMap deve se posicionar como:

> "A plataforma completa do povo de axé: encontre terreiros, gerencie sua casa, conecte-se com a comunidade e adquira artigos religiosos — tudo em um só lugar."

## Estratégia de Entrada

1. **MVP:** Foco em diretório + busca + perfil de terreiro (diferencial: qualidade de UX impecável)
2. **Fase 2:** Adicionar avaliações + favoritos + compartilhamento (engajamento)
3. **Fase 3:** SaaS básico para terreiros (agenda + membros) — monetização começa
4. **Fase 4:** Marketplace + comunidade (rede completa)
5. **Fase 5:** IA + APIs públicas + enterprise
