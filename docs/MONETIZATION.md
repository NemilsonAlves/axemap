# AxéMap — Monetização

## Princípio Central

**O AxéMap é gratuito para a comunidade.**

A monetização sustenta a infraestrutura sem jamais:
- Vender confiança
- Vender verificação
- Vender autoridade
- Vender legitimidade religiosa
- Manipular avaliações
- Alterar denúncias por dinheiro
- Melhorar posição orgânica por pagamento

## Recursos Premium (Pagos)

### Comunidade Pro
Ferramentas SaaS para gestão avançada:
- Página avançada
- Analytics da comunidade
- Gestão de eventos avançada
- Comunicação com seguidores
- Estatísticas detalhadas
- Personalização de perfil

**Importante: plano premium NÃO aumenta Trust Score.**

### Profissional
Para pesquisadores, artistas, produtores, fotógrafos:
- Perfil profissional destacado
- Portfolio
- Contato direto
- Materiais para download

### Institucional
Para federações, institutos, universidades:
- Recursos avançados de gestão
- Analytics
- Integração API

---

## Publicidade (AxéMap ADS)

Todo anúncio exibe rótulo obrigatório: **PATROCINADO** ou **PUBLICIDADE**.

Segmentação disponível:
- Por cidade/estado
- Por categoria
- Por placement (home, mapa, cards, etc.)

O anúncio **não** altera:
- Posição orgânica no ranking
- Trust Score
- Verificação
- Avaliações

## Usuários × Monetização

| Perfil | Relação com Monetização |
|---|---|
| Comunidade gratuita | Acesso público completo, sem pagamento |
| Apoiador | Contribui voluntariamente para manter a infraestrutura |
| Comunidade premium | Usa ferramentas SaaS pagas |
| Profissional | Usa perfil profissional pago |
| Organização | Usa recursos institucionais |
| Empresa/anunciante | Compra publicidade identificada |
| Campanha | Arrecada para objetivo específico |
| Patrocinador | Contrato de patrocínio institucional |
