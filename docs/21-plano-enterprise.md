# 21 — Plano Enterprise

## Proposta de Valor

> "Dados, APIs e ferramentas para governos, pesquisadores e organizações que trabalham pela liberdade religiosa e preservação cultural."

## Clientes Enterprise

| Segmento | Cliente Potencial | Necessidade |
|----------|------------------|-------------|
| **Governo Federal** | Ministério da Igualdade Racial, Fundação Palmares | Mapeamento nacional de terreiros, dados para políticas públicas |
| **Governos Estaduais** | Secretarias de Igualdade Racial, Cultura | Mapa estadual, dados regionalizados |
| **Prefeituras** | Secretarias de Direitos Humanos, Turismo | Mapa municipal, turismo religioso |
| **Universidades** | PPGs em Antropologia, Sociologia, Ciências da Religião | Dados para pesquisa acadêmica |
| **ONGs** | Criola, Educafro, Ceap | Dados sobre intolerância, subsídios para advocacy |
| **Organismos Internacionais** | UNESCO, UNDP | Dados sobre liberdade religiosa no Brasil |

## Produtos Enterprise

### 1. API de Dados Governamentais
| Feature | Descrição |
|---------|-----------|
| Endpoints | REST + GeoJSON |
| Dados | Agregados, anonimizados, georreferenciados |
| Atualização | Diária / Semanal |
| Suporte | SLA 99.9%, suporte prioritário |
| Preço | R$ 1.500-5.000/mês (conforme volume) |

### 2. Mapa Interativo da Intolerância Religiosa
| Feature | Descrição |
|---------|-----------|
| Dashboard | Heatmap de denúncias por região |
| Dados | Anônimos, agregados por bairro/cidade/estado |
| Período | Visualização histórica (mês a mês) |
| Exportação | PDF, CSV, GeoJSON |
| Preço | R$ 2.000/mês + taxa de implementação |

### 3. Plataforma de Pesquisa Acadêmica
| Feature | Descrição |
|---------|-----------|
| Acesso | Dados abertos gratuitos com atribuição |
| Dataset | CSV estruturado com dados agregados |
| Documentação | Dicionário de dados + metodologia |
| Citação | Obrigatória — aumenta alcance da marca |
| Preço | Grátis (missão social) |

### 4. White-Label para Federações e Orgãos
| Feature | Descrição |
|---------|-----------|
| Marca própria | Portal com logo do cliente |
| Subdomínio | mapa.secretariasp.gov.br |
| Dados | Filtrados por jurisdição |
| Customização | Cores, logo, domínio |
| Preço | R$ 5.000-15.000 (implementação) + R$ 2.000/mês |

### 5. SaaS Enterprise para Grandes Terreiros
| Feature | Descrição |
|---------|-----------|
| Múltiplas casas | Gerencie filiais ou rede de terreiros |
| White-label | terreiro.domindoproprietario.com.br |
| API privada | Integração com sistemas existentes |
| Suporte | CSM dedicado, onboarding presencial |
| Preço | R$ 299/mês |

| Mês 15 | Propor parceria com UNESCO para dados de liberdade religiosa |

## Impacto Social e Políticas Públicas

O AxéMap pode se tornar fonte oficial de dados sobre:
- Distribuição geográfica de terreiros
- Perfil socioeconômico das comunidades
- Incidência de intolerância religiosa
- Necessidades de políticas públicas
- Impacto do turismo religioso

**Diferencial:** Enquanto o IBGE depende de autodeclaração, o AxéMap mapeia terreiros reais com dados verificados.
