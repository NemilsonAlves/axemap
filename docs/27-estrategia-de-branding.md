### Logo (Conceito)

```
[Ícone]    [Texto]
  ⬆        AxéMap
  ───
  │ │
```

**Conceito do ícone:** Um ponto de mapa (📍) estilizado com elementos que remetem à cultura afro:
- Caminho sinuoso (jornada espiritual)
- Círculo (comunidade, axé)
- Linhas que remetem a colares (fios de conta)

**NÃO usar:** 
- Símbolos religiosos específicos (para manter neutralidade)
- Estereótipos (não coisificar a cultura)
- Apropriação visual não consultada

### Tom Fotográfico

- **Fotos reais** de terreiros (nada de stock photos genéricas)
- **Cores quentes** e naturais
- **Pessoas reais** em contexto (giras, celebrações, dia a dia)
- **Arquitetura** dos terreiros (valorização do espaço físico)
- **Detalhes** (objetos rituais, ervas, instrumentos — com respeito)

## Voz da Marca

### Diretrizes de Conteúdo

| Faça | Não faça |
|------|----------|
| Use linguagem inclusiva | Use termos pejorativos (mesmo internalmente) |
| Explique termos religiosos | Presuma conhecimento prévio |
| Seja acolhedor | Seja informal demais |
| Seja transparente sobre processos | Esconda algoritmos ou scores |
| Trate todas tradições com igual respeito | Hierarquize vertentes |
| Use "terreiro", "casa", "comunidade" | Use "seita" ou "culto" |

## Brand Experience

### Touchpoints

| Touchpoint | Experiência |
|-----------|-------------|
| **Homepage** | Busca simples, mapa acolhedor, cards com score visível |
| **Cadastro Terreiro** | Guiado, acolhedor, com dicas de como completar perfil |
| **Perfil Terreiro** | Rico, transparente, score explicado, fotos reais |
| **Resultado Busca** | Score como principal elemento de ordenação |
| **Notificações** | Úteis, respeitosas, não intrusivas |
| **Suporte** | Humano, via WhatsApp, tempo de resposta < 5min |

### Emoções da Marca

| Emoção | Onde aparece |
|--------|-------------|
| **Confiança** | Score, verificação, moderação |
| **Pertencimento** | Comunidade, grupos, eventos |
| **Segurança** | LGPD, moderação, ambiente seguro |
| **Descoberta** | Busca, recomendação, match |
| **Orgulho** | Perfil verificado, selos, reputação |

## Brand Guidelines Internas

- **Neutralidade absoluta:** Nenhum funcionário ou contribuidor deve expressar preferência religiosa em comunicações oficiais
- **Crise de reputação:** Qualquer incidente de intolerância na plataforma deve ter resposta em < 2h
- **LGPD como valor:** Tratar dados de religião com o máximo cuidado — é dado sensível
- **Open book:** Scores e algoritmos são documentados publicamente
